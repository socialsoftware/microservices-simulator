### P1–P4 Consistency

Authoritative definitions, from `docs/concepts/rule-enforcement-patterns.md` § Quick Reference and
§ Decision Guide:

- **P1** — single-aggregate state rule (scalars, own collections, or cached snapshot fields);
  `verifyInvariants()` in the aggregate; strong.
- **P2** — cache state from another aggregate, never blocking; `getEventSubscriptions()` + handler
  chain; eventual.
- **P3** — synchronous service-level check: own-table uniqueness **or** validation of a
  saga-assembled DTO; guard in `*Service.java` inside `@Transactional(SERIALIZABLE)`; strong.
- **P4a** — precondition implicit in a saga fetch query (the query throws when unmet); no code.
- **P4b** — invariant holds because the saga passes the same value to two aggregates; no code.
